# Torres del Mall

Landing residencial en HTML, CSS y JavaScript puro. Incluye portada con carrusel, presentación, catálogo de tipologías, visión, acordeón, galería, beneficios, equipo y contacto.

## Vista local

Abre `index.html` en tu navegador. También puedes servir el proyecto desde la carpeta extraída con Python 3:

```sh
python3 -m http.server 8080
```

Visita `http://localhost:8080`. El sitio funciona sin instalar dependencias y usa imágenes locales.

## Editar con Codex

Abre la carpeta del proyecto en Codex. Edita los textos y el orden en `index.html`, el diseño y las animaciones en `styles.css`, y las tipologías e interacciones en `main.js`. Sustituye los JPG de `assets/` conservando sus nombres o actualiza las rutas correspondientes.

Las imágenes generadas, las tipologías y los textos son referenciales. Valida el contenido comercial antes de publicarlo. El formulario de demostración descarga una consulta de texto. Para abrir un borrador en la aplicación de correo del visitante, coloca el correo oficial en `contactEmail` al principio de `main.js`.

## GitHub

Sube el contenido de la carpeta extraída a la raíz de un repositorio. Para alojarlo con GitHub Pages, selecciona la rama publicada y la carpeta raíz como fuente. Las rutas relativas funcionan bajo el subdirectorio del repositorio.
